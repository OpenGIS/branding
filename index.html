OpenGIS Styleguide

The single source for OpenGIS docs and site styling. One hosted stylesheet — assets/css/ogis.css — bundles Pico CSS, the OpenGIS theme and the highlight.js syntax palette, so consumers link it and, for highlighted code, add the highlight.js runtime. It also ships the OGIS logo set, a small page UI and an optional background map. A change here updates every site that links it.

Every section below is both the documentation and the live demo.

Quick Start

Link the one hosted stylesheet — it already carries Pico CSS, the OpenGIS theme and the syntax palette. Add highlight.js only if you want highlighted code blocks. The default is to load directly from the ogis.org domain; forking or self-hosting takes one env value (VITE_PRODUCTION_URL), which drives the canonical link and these examples. 

<link rel="stylesheet" href="%VITE_PRODUCTION_URL%/assets/css/ogis.css">
<link rel="icon" href="%VITE_PRODUCTION_URL%/assets/img/logo-green.png">
<!-- Optional: highlight code blocks -->
<script src="/your/highlight.min.js"></script>
<script>hljs.highlightAll();</script>

Map BG

One optional module gives any element a random country background, powered by the hosted Waymark-JS v1 viewer. Mark a container with data-background-map and load the module once; it injects the viewer's CSS, jQuery and bundle (see Dependencies) and centres a country at zoom 8. The map is decorative and fixed: random and non-interactive, with no scroll, drag, pinch, double-click or keyboard zoom.

Live demo — the container above carries only the attribute and a height. Reload the page for a different country. This page's header wears the same module with data-background-map="invert", since the header band is always dark. 

<!-- Any block; set its height however you like. -->
<div data-background-map style="height: 220px"></div>

<script src="%VITE_PRODUCTION_URL%/assets/js/background-map.js" defer></script>

The built file exposes window.BackgroundMap.init() and window.BackgroundMap.refresh() for containers added after load. Force the always-dark look on a dark band with the invert modifier: 

<div data-background-map="invert"></div>
<!-- or -->
<div class="background-map--invert" data-background-map></div>

Dark vs Light

The theme ships a light and a dark token set. With nothing set it follows your operating system through prefers-color-scheme. A page can force a scheme by setting data-theme="light" or data-theme="dark" on the root element; removing the attribute returns to the OS default. The control below demonstrates it live — the whole page switches, and nothing is stored. 

<!-- Force a scheme; omit the attribute to follow the OS. -->
<html data-theme="dark">

Light warms the page to #fcfaf5 with sage #f0f1e6 bands and an AA-compliant green for links (#0a7d0a). Dark deepens the org surfaces to #000b00 / #001800 with the neon accent #0dd70d. Orange (#b3571f / #dc8f4e) is a first-class accent in both. Add <meta name="color-scheme" content="light dark"> so the browser agrees with the theme about which scheme is available.

Typography

Full monospace throughout at 15 px/1.65; code at 13 px. Blockquotes step up to a larger warm serif (25 px) with a hanging opening quote mark, a closing mark and an accent rule. No webfonts, so there are zero font requests.

Code

The syntax palette lives in ogis.css alongside the rest of the theme, keyed on highlight.js language classes. The styleguide loads highlight.js 11.12.0 from npm; give a block a language-* class and it highlights on load. Every block has a one-click copy control in the top-right; long lines wrap, so nothing scrolls sideways.

Inline code is a plain chip by default — map.on("ready") — but a chip carrying language-* highlights: map.on("ready"). 

// Tile a Waymark map
import { Map } from "waymark-js";

const map = new Map("map", { style: "terrain" });
map.on("ready", () => {
  console.log("tiles loaded");
});
